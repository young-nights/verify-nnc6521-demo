## 1. 项目概述

verify-nnc6521-demo 是一个基于 **STM32F103RCT6 + RT-Thread** 的 NNC6521 双芯片验证 Demo 项目。该项目用于验证 NNC6521 刺激波形发生器芯片的功能和性能。

本文档定义了基于 DJM-V10 微电流美容仪需求的 **9 种预定义波形** 的详细设计方案，涵盖波形规格、电流映射、寄存器配置和测试验证方案。

---

## 2. 硬件平台描述

### 2.1 MCU
- **型号**: STM32F103RCT6 (ARM Cortex-M3, 72 MHz)
- **操作系统**: RT-Thread

### 2.2 NNC6521 双芯片引脚映射

| 信号 | NNC6521-1 | NNC6521-2 |
|------|-----------|-----------|
| MOSI | PA7 | PB15 |
| CSN | PA4 | PB12 |
| SCLK | PA5 | PB13 |
| MISO | PA6 | PB14 |
| CHIP_EN | PC5 | PC7 |
| INTB | PC4 | PC6 |

### 2.3 外设
- **调试串口**: USART1
- **独立按键 K1**: PC0（低电平有效）

### 2.4 NNC6521 时钟
- **PCLK**: 2 MHz (PCLK_DIV_1)
- **系统时钟公式**: 半波时钟点数 = PCLK / (2 × 目标频率)

## 3. 波形系统总体设计

### 3.1 九种波形规格表

| ID | 名称 | 电流范围 (mA) | 频率 (Hz) | 脉宽 (μs) | 波形类型 | 描述 |
|----|------|--------------|-----------|-----------|---------|------|
| 1 | Power Smooth | 30 ~ 80 | 50 | 300 | 对称方波 | 强力平滑 |
| 2 | Burst Train | 30 ~ 80 | 50 (burst 10 Hz) | 300 | 突发训练 | 突发脉冲串 |
| 3 | Gentle Smooth | 20 ~ 60 | 35 | 300 | 对称方波 | 温和平滑 |
| 4 | Deep Sculpt | 30 ~ 80 | 40 ~ 50 | 4 kHz 载波 | 平衡方波 | 深层塑形 |
| 5 | Soft Sculpt | 30 ~ 80 | 30 ~ 40 | 2 ~ 4 kHz | 正弦波 | 柔和塑形 |
| 6 | Circulation Sculpt | 20 ~ 60 | 2 ~ 10 | 4 kHz 载波 | 平衡正弦 | 循环塑形 |
| 7 | Smooth & Firm | 15 ~ 50 | 80 ~ 100 | 400 | 三角波 | 平滑紧致 |
| 8 | Lymphatic Drainage | 15 ~ 40 | 5 | 450 | 低频正弦 | 淋巴引流 |
| 9 | Soothing Ending | 10 ~ 30 | 10 | — | 正弦波 | 舒缓收尾 |

### 3.2 电流映射规则

用户通过百分比 (0 ~ 100%) 控制电流强度：

```
actual_current = min_current + (max_current - min_current) × percent / 100
```

**示例**: 波形 1 (30~80 mA), percent = 50 → 30 + (80 - 30) × 50 / 100 = 55 mA

### 3.3 波形生成方式选择

NNC6521 支持三种波形生成方式：

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| 预加载波形 (Preloaded) | 芯片内置正弦/脉冲/三角波，通过寄存器选择 | 简单标准波形 |
| 自定义 SPI 波形 (Customized SPI) | 通过 SPI 写入归一化浮点数组，由 DAC 输出 | 复杂/非标准波形 |
| 幅度调制 (Amplitude Modulation) | 包络线 + 载波调制输出 | 需要载波调制的波形 |

### 3.4 采样点数选择规则

| 波形 ID | 采样点数 | 理由 |
|---------|---------|------|
| 1, 2, 3, 7, 8, 9 | 64 点 | 低频/简单波形 |
| 4, 5, 6 | 128 点 | 高频/复杂波形 |

## 4. 各波形详细实现方案

### 4.1 波形 1: Power Smooth (强力平滑)

- **生成方式**: 预加载脉冲波 (WAVEFORM_PULSE)
- **波形类型**: 对称方波
- **频率**: 50 Hz
- **脉宽**: 300 μs

**寄存器参数计算**:
- 半波时钟点数: 2,000,000 / (2 × 50) = **20,000**
- 静默时间: 300 × 10⁻⁶ × 2,000,000 = **600** 时钟周期
- 休息时间: 0 (无死区)

**调用接口**:
```c
nnc6521_preloaded_waveform(chip_id, CH0, WAVEFORM_PULSE, 64, ci,
                           20000, 20000, 600, 0);
```

---

### 4.2 波形 2: Burst Train (突发训练)

- **生成方式**: 自定义 SPI 波形 (WAVEFORM_SPI)
- **波形类型**: 突发脉冲串
- **频率**: 50 Hz (突发频率 10 Hz)
- **脉宽**: 300 μs

**实现方案**:
使用 64 点自定义脉冲数组（前 32 点为 1.0，后 32 点为 0.0），产生 burst-on/off 效果。

**寄存器参数计算**:
- 半波时钟点数: 2,000,000 / (2 × 50) = **20,000**
- 静默时间: 600 时钟周期
- 休息时间: 0

**调用接口**:
```c
nnc6521_customized_waveform(chip_id, CH0, 64, burst_pulse_64,
                            max_current, 20000, 20000, 600, 0, 0);
```

---

### 4.3 波形 3: Gentle Smooth (温和平滑)

- **生成方式**: 预加载脉冲波 (WAVEFORM_PULSE)
- **波形类型**: 对称方波
- **频率**: 35 Hz
- **脉宽**: 300 μs

**寄存器参数计算**:
- 半波时钟点数: 2,000,000 / (2 × 35) = **28,571**
- 静默时间: 600 时钟周期
- 休息时间: 0

**调用接口**:
```c
nnc6521_preloaded_waveform(chip_id, CH0, WAVEFORM_PULSE, 64, ci,
                           28571, 28571, 600, 0);
```

---

### 4.4 波形 4: Deep Sculpt (深层塑形)

- **生成方式**: 自定义 SPI 波形 (WAVEFORM_SPI)
- **波形类型**: 平衡方波 (4 kHz 载波)
- **频率**: 40 ~ 50 Hz
- **脉宽**: 4 kHz 载波

**实现方案**:
使用 128 点自定义脉冲数组，实现 4 kHz 载波被 40~50 Hz 包络调制的效果。

**寄存器参数计算**:
- 半波时钟点数 (50 Hz): **20,000**
- 静默时间 (4 kHz): 2,000,000 / (2 × 4000) = **250** 时钟周期
- 休息时间: 0

**调用接口**:
```c
nnc6521_customized_waveform(chip_id, CH0, 128, deep_sculpt_pulse_128,
                            max_current, 20000, 20000, 250, 0, 0);
```

---

### 4.5 波形 5: Soft Sculpt (柔和塑形)

- **生成方式**: 自定义 SPI 波形 (WAVEFORM_SPI)
- **波形类型**: 正弦波 (2 ~ 4 kHz 载波)
- **频率**: 30 ~ 40 Hz
- **脉宽**: 2 ~ 4 kHz

**实现方案**:
使用 128 点正弦数组，正弦波本身作为 30~40 Hz 基波。

**寄存器参数计算**:
- 半波时钟点数 (40 Hz): 2,000,000 / (2 × 40) = **25,000**
- 静默时间: 0 (连续正弦波无需静默)
- 休息时间: 0

**调用接口**:
```c
nnc6521_customized_waveform(chip_id, CH0, 128, normalized_sine_waveform_128,
                            max_current, 25000, 25000, 0, 0, 1);
```

---

### 4.6 波形 6: Circulation Sculpt (循环塑形)

- **生成方式**: 幅度调制 (Amplitude Modulation)
- **波形类型**: 平衡正弦 (4 kHz 载波)
- **频率**: 2 ~ 10 Hz
- **脉宽**: 4 kHz 载波

**实现方案**:
使用 64 点正弦包络数组，载波频率 4 kHz。包络线频率 = PCLK / (64 × interval_cycles)。

**寄存器参数计算**:
- 载波频率: 4 kHz → ALT_LIM = 2,000,000 / (2 × 4000) = **250**
- 包络间隔 (10 Hz): 2,000,000 / (64 × 10) = **3,125**
- 静默时间: 0
- 休息时间: 0

**调用接口**:
```c
nnc6521_amplitude_modulation(chip_id, CH0, 64, normalized_sine_waveform_64,
                             max_current, 250, 0, 3125);
```

---

### 4.7 波形 7: Smooth & Firm (平滑紧致)

- **生成方式**: 预加载三角波 (WAVEFORM_TRIANGLE)
- **波形类型**: 三角波
- **频率**: 80 ~ 100 Hz
- **脉宽**: 400 μs

**寄存器参数计算**:
- 半波时钟点数 (100 Hz): 2,000,000 / (2 × 100) = **10,000**
- 静默时间: 400 × 10⁻⁶ × 2,000,000 = **800** 时钟周期
- 休息时间: 0

**调用接口**:
```c
nnc6521_preloaded_waveform(chip_id, CH0, WAVEFORM_TRIANGLE, 64, ci,
                           10000, 10000, 800, 0);
```

---

### 4.8 波形 8: Lymphatic Drainage (淋巴引流)

- **生成方式**: 自定义 SPI 波形 (WAVEFORM_SPI)
- **波形类型**: 低频正弦
- **频率**: 5 Hz
- **脉宽**: 450 μs

**实现方案**:
使用 64 点正弦数组，低频 5 Hz 输出。

**寄存器参数计算**:
- 半波时钟点数: 2,000,000 / (2 × 5) = **200,000**
- 静默时间: 450 × 10⁻⁶ × 2,000,000 = **900** 时钟周期
- 休息时间: 0

**调用接口**:
```c
nnc6521_customized_waveform(chip_id, CH0, 64, normalized_sine_waveform_64,
                            max_current, 200000, 200000, 900, 0, 1);
```

### 4.9 波形 9: Soothing Ending (舒缓收尾)

- **生成方式**: 预加载正弦波 (WAVEFORM_SINE)
- **波形类型**: 正弦波
- **频率**: 10 Hz

**寄存器参数计算**:
- 半波时钟点数: 2,000,000 / (2 × 10) = **100,000**
- 静默时间: 0 (连续正弦波)
- 休息时间: 0

**调用接口**:

```c
                           100000, 100000, 0, 0);
```

## 5. NNC6521 驱动接口调用说明

### 5.1 初始化

```c
nnc6521_gpio_init();                    // 初始化 GPIO 引脚
nnc6521_init(NNC6521_CHIP_1);           // 初始化芯片 1
nnc6521_init(NNC6521_CHIP_2);           // 初始化芯片 2
```

### 5.2 预加载波形输出

```c
void nnc6521_preloaded_waveform(
    uint8_t  chip_id,               // 芯片 ID (0 或 1)
    uint8_t  u8_Channel,            // 通道 (CH0=0, CH1=1)
    uint8_t  u8_Waveform,           // 波形类型 (SINE/PULSE/TRIANGLE)
    uint8_t  u8_PointNum,           // 采样点数 (64 或 128)
    uint8_t  u8_CI,                 // 电流驱动强度
    uint16_t u32_Positive_Interval, // 正半波时钟周期
    uint16_t u32_Negative_Interval, // 负半波时钟周期
    uint32_t u32_Silent_Time,       // 静默时间 (时钟周期)
    uint16_t u16_Rest_Time          // 休息时间 (时钟周期)
);
```

### 5.3 自定义 SPI 波形输出

```c
void nnc6521_customized_waveform(
    uint8_t  chip_id,                    // 芯片 ID
    uint8_t  u8_Channel,                 // 通道
    uint8_t  u8_PointNum,                // 采样点数
    float   *f_Normalized_array,         // 归一化波形数组 (0.0 ~ 1.0)
    uint32_t u32_Max_current,            // 最大电流 (mA)
    uint16_t u32_Positive_Interval,      // 正半波时钟周期
    uint16_t u32_Negative_Interval,      // 负半波时钟周期
    uint32_t u32_Silent_Time,            // 静默时间
    uint16_t u16_Rest_Time,              // 休息时间
    uint8_t  u8_Asymmetric_Symmetric     // 0=非对称, 1=对称
);
```

### 5.4 幅度调制波形输出

```c
void nnc6521_amplitude_modulation(
    uint8_t  chip_id,                    // 芯片 ID
    uint8_t  u8_Channel,                 // 通道
    uint8_t  u8_PointNum,                // 包络线采样点数
    float   *f_Normalized_Envelope_array, // 归一化包络数组
    uint32_t u32_Max_current,            // 最大电流 (mA)
    uint16_t u16_Carrier,                // 载波半波时钟周期
    uint32_t u32_Silent_Time,            // 静默时间
    uint16_t u16_Interval                // 包络间隔时钟周期
);
```

### 5.5 AWG 使能/禁用

```c
void nnc6521_awg_enable_disable(
    uint8_t chip_id,                // 芯片 ID
    uint8_t AWG_ChannelNum,         // 通道
    uint8_t Enable_Disable          // 1=使能, 0=禁用
);
```

## 6. 波形配置模块接口

### 6.1 波形配置结构体

```c
typedef struct {
    uint8_t     id;              // 波形 ID (1~9)
    const char *name;            // 波形名称
    const char *description;     // 波形描述
    uint32_t    min_current;     // 最小电流 (mA)
    uint32_t    max_current;     // 最大电流 (mA)
    uint16_t    frequency;       // 主频率 (Hz)
    uint16_t    pulse_width_us;  // 脉宽 (μs)
    uint8_t     waveform_type;   // 波形类型枚举
    uint8_t     gen_method;      // 生成方式 (0=预加载, 1=自定义SPI, 2=幅度调制)
    uint8_t     point_num;       // 采样点数
    uint16_t    half_wave_clk;   // 半波时钟点数
    uint32_t    silent_time;     // 静默时间
    uint16_t    rest_time;       // 休息时间
    uint16_t    carrier_freq;    // 载波频率 (仅幅度调制)
    uint16_t    am_interval;     // 包络间隔 (仅幅度调制)
    float      *waveform_data;   // 波形数据指针
} waveform_config_t;
```

### 6.2 核心函数

```c
/* 根据波形 ID 和电流百分比，配置 NNC6521 输出对应波形 */
void waveform_apply(uint8_t chip_id, uint8_t channel,
                    uint8_t waveform_id, uint8_t percent);

/* 电流百分比映射 */
uint32_t waveform_calc_current(uint8_t waveform_id, uint8_t percent);

/* 获取波形配置 */
const waveform_config_t* waveform_get_config(uint8_t waveform_id);
```

## 7. 测试验证方案

### 7.1 测试流程

1. 上电后，系统初始化 NNC6521 双芯片
2. 默认加载波形 1 (Power Smooth)，电流百分比 50%
3. 每次按下 K1 按键，切换到下一个波形 (1→2→...→9→1)
4. 串口输出当前波形信息（名称、电流、频率、波形类型）

### 7.2 串口输出格式

```
========================================
Waveform #1: Power Smooth
  Current: 55 mA (50%)
  Frequency: 50 Hz
  Type: Preloaded Pulse
========================================
```

### 7.3 验证检查项

| 检查项 | 预期结果 |
|--------|---------|
| K1 按键切换 | 9 种波形循环切换 |
| 串口输出 | 每次切换打印波形信息 |
| 波形输出 | NNC6521 CH0 输出正确波形 |
| 电流范围 | 实际电流在指定范围内 |
| 频率精度 | 实际频率在指定范围内 |
