# NNC6521 测试开发板 — 硬件资源描述

## 1. 主控芯片

| 项目 | 参数 |
|------|------|
| 型号 | STM32F103RCT6 |
| 内核 | ARM Cortex-M3 |
| 主频 | 72 MHz（HSE 8MHz + PLL ×9） |

| 封装 | LQFP64 |

## 2. NNC6521 双芯片引脚映射

本开发板搭载 **2 颗 NNC6521** 芯片，使用**软件 SPI**（GPIO 位操作）通信。

### NNC6521-1（SPI 通道 1）

| STM32 引脚 | 功能 | NNC6521-1 引脚 | GPIO 模式 |
|-----------|------|---------------|----------|
| PA4 | SPI1_CS (CSN) | CSN | 推挽输出，高速，空闲高电平 |
| PA5 | SPI1_SCLK | SCLK | 推挽输出，高速，空闲低电平 (CPOL=0) |
| PA6 | SPI1_MISO | MISO | 浮空输入 |
| PA7 | SPI1_MOSI | MOSI | 推挽输出，高速 |
| PC4 | INTB | INTB | 浮空输入（中断输出，低电平有效） |
| PC5 | CHIP_EN | CHIP_EN | 推挽输出，高速，初始低电平 |

### NNC6521-2（SPI 通道 2）

| STM32 引脚 | 功能 | NNC6521-2 引脚 | GPIO 模式 |
|-----------|------|---------------|----------|
| PB12 | SPI2_CS (CSN) | CSN | 推挽输出，高速，空闲高电平 |
| PB13 | SPI2_SCLK | SCLK | 推挽输出，高速，空闲低电平 (CPOL=0) |
| PB14 | SPI2_MISO | MISO | 浮空输入 |
| PB15 | SPI2_MOSI | MOSI | 推挽输出，高速 |
| PC6 | INTB | INTB | 浮空输入（中断输出，低电平有效） |
| PC7 | CHIP_EN | CHIP_EN | 推挽输出，高速，初始低电平 |

## 3. 开发板辅助控制引脚

根据参考设计（NNC6521_General_Demo），开发板上以下 GPIO 引脚需要配置为**推挽输出、高电平**，用于开发板上的电平转换/使能电路：

| STM32 引脚 | 功能 | GPIO 模式 | 初始电平 |
|-----------|------|----------|---------|
| PB0 | 开发板使能信号 1 | 推挽输出，高速 | HIGH |
| PB1 | 开发板使能信号 2 | 推挽输出，高速 | HIGH |
| PB10 | 开发板使能信号 3 | 推挽输出，高速 | HIGH |
| PB11 | 开发板使能信号 4 | 推挽输出，高速 | HIGH |

> **⚠️ 重要**：这 4 个引脚在参考项目中被初始化为高电平输出，若未配置可能导致 NNC6521 输出级未使能，示波器测量无波形。

| 按键 | 引脚 | 有效电平 | GPIO 配置 |

## 6. NNC6521 芯片上电时序

```
CHIP_EN 拉低 ──→ 延时 ≥1ms ──→ CHIP_EN 拉高 ──→ 延时 ≥5ms ──→ SPI 可用
```

> **⚠️ 关键**：CHIP_EN 拉高后需要等待 **≥5ms** 让芯片内部完成初始化，之后才能进行 SPI 寄存器读写。过早通信会导致写入失败，波形无法输出。

## 7. SPI 通信协议

- **模式**：CPOL=0, CPHA=0, MSB 先传
- **写寄存器**：4 字节时序 `[addr, cmd=0x80, data, 0x00]`（数据在 byte 2，byte 3 固定为 0x00）
- **写波形寄存器**：4 字节时序 `[addr, cmd=0xC0, data, 0x00]`（数据在 byte 2，byte 3 固定为 0x00）
- **读寄存器**：3 字节时序 `[addr, cmd=0x00, dummy]`，数据在第 3 字节返回
- **OTP 读取**：先写地址到 0x1D，发命令 0x54 到 0x1B，从 0x1E 读数据，最后写 0x50 到 0x1B

### SPI 位操作时序

位操作时序（CPOL=0, CPHA=0, 72MHz 主频）：
- MOSI 数据建立：4x NOP (~55ns)
- SCLK 上升沿后：8x NOP（高电平保持 + 额外裕量）
- SCLK 下降沿后：4x NOP（低电平保持）
- CSN 拉低/拉高前后：4x NOP

## 8. 波形输出参数（默认 Waveform 1: Power Smooth）

| 参数 | 值 | 说明 |
|------|------|------|
| 波形类型 | 方波 (SQUARE) | 预加载模式 |
| 采样点数 | 64 | 半波点数 |
| 频率 | 50 Hz | half_wave_clk = 20000 |
| 脉冲宽度 | 300 µs | silent_time = 600 |
| 电流范围 | 30~80 mA | 50% → 55 mA |

## 9. 模拟前端使能

`wavegen_config()` 中使用 `|= 0x1F` 设置 `ANA_ENABLE_REG`：
- bit0: DRIVERA_AMP_EN（驱动放大器使能）
- bit1: DRIVERA_CSAMP_EN（驱动放大器电流检测使能）
- bit2: COMP_EN（比较器使能）
- bit3: IDAC_EN（IDAC 使能）
- bit4: VDAC_EN（VDAC 使能）

## 10. 完整引脚总览

```
STM32F103RCT6 引脚分配
├── NNC6521-1 SPI
│   ├── PA4  → CSN (CS)
│   ├── PA5  → SCLK
│   ├── PA6  → MISO
│   ├── PA7  → MOSI
│   ├── PC4  → INTB
│   └── PC5  → CHIP_EN
├── NNC6521-2 SPI
│   ├── PB12 → CSN (CS)
│   ├── PB13 → SCLK
│   ├── PB14 → MISO
│   ├── PB15 → MOSI
│   ├── PC6  → INTB
│   └── PC7  → CHIP_EN
├── 开发板使能
│   ├── PB0  → 使能信号 1 (HIGH)
│   ├── PB1  → 使能信号 2 (HIGH)
│   ├── PB10 → 使能信号 3 (HIGH)
│   └── PB11 → 使能信号 4 (HIGH)
├── 调试串口
│   ├── PA9  → USART1_TX
│   └── PA10 → USART1_RX
└── 用户按键
    └── PC0  → K1 (上拉输入，低电平有效)
```
